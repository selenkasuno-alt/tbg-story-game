# Рукопись ТБГ — релизный MVP

Полноценная серверная версия многопользовательской писательской игры сообщества «Территория без границ».

## Что уже работает

- два режима: **Классика** и **Тайный диверсант**;
- 14 жанров и 280 стартовых сцен;
- 120 секретных заданий диверсанта;
- создание комнаты и вход по пятизначному коду или прямой ссылке;
- минимум 3 игрока;
- каждый участник играет со своего браузера/телефона;
- циклическая очередь игроков;
- игрок видит только предыдущий фрагмент, а не всю рукопись;
- в «Тайном диверсанте» секретное задание видит только текущий игрок;
- задания не повторяются, пока не будет исчерпан банк;
- ведущий может пропустить отсутствующего игрока; пропуск не уменьшает число запланированных фрагментов;
- после финала по умолчанию показывается цельный рассказ;
- отдельный режим «Кто что писал?»;
- отдельное «Раскрытие диверсантов»;
- восстановление игрока после обновления страницы по локальному токену;
- адаптивный интерфейс для телефона и ПК;
- минимальная VK Bridge-инициализация: внутри VK имя пользователя может подставиться автоматически.

## Быстрый тест на компьютере

Нужен Node.js 18 или новее.

Windows: дважды нажать `start_windows.bat`.

Либо в терминале:

```bash
node server.js
```

Затем открыть `http://localhost:3000`.

Чтобы проверить настоящий мультиплеер локально, открой комнату в разных браузерах/инкогнито-окнах. Для теста с телефона в одной Wi‑Fi сети используй IP компьютера, например `http://192.168.1.20:3000`.

## Публикация

Проект не требует npm-пакетов: сервер работает на стандартном Node.js. Для публичной работы нужен HTTPS-хостинг, который запускает `node server.js` или Dockerfile.

Для сохранения активных комнат между перезапусками желательно подключить постоянный диск и задать `DATA_DIR=/data`. Без него игра всё равно работает, но на хостингах с временной файловой системой комнаты могут исчезнуть после перезапуска контейнера.

## ВК

Frontend уже адаптирован под встраивание и содержит необязательную инициализацию VK Bridge. После размещения проекта на HTTPS-домене этот адрес можно использовать как URL веб-приложения/мини-приложения в настройках ВК. Точные названия полей и требования кабинета ВК следует сверить в актуальном интерфейсе разработчика перед публикацией.

## Безопасность игрового процесса

Скрытые данные выдаёт сервер, а не CSS: пользователь, который сейчас не ходит, не получает предыдущий фрагмент и секретное задание в ответе API. Полная рукопись и задания становятся доступны после завершения партии.
