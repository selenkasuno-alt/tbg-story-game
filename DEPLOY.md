# Развёртывание

## Вариант 1 — любой Node.js-хостинг

1. Загрузить всю папку проекта.
2. Команда запуска: `node server.js`.
3. Переменная окружения `PORT` обычно назначается хостингом автоматически.
4. Если хостинг поддерживает постоянный диск, подключить его и задать `DATA_DIR` на этот путь.
5. После запуска проверить `https://ВАШ-ДОМЕН/api/meta` — должен открыться JSON со списком жанров.
6. Открыть главную страницу, создать комнату и проверить вход с другого браузера.

## Вариант 2 — Docker

```bash
docker build -t tbg-story-game .
docker run -p 3000:3000 -v tbg-data:/data -e DATA_DIR=/data tbg-story-game
```

## Перед размещением в ВК

- публичный адрес должен работать по HTTPS;
- создать тестовую комнату на публичном адресе;
- зайти вторым и третьим игроком с других устройств;
- проверить режим «Тайный диверсант»: задание должно видеть только текущий игрок;
- проверить финальный цельный рассказ, «Кто что писал?» и «Раскрыть диверсантов»;
- после этого указать HTTPS-адрес приложения в кабинете VK Mini Apps/приложений сообщества согласно текущему интерфейсу ВК.
